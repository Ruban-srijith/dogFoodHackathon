# DogFood Hackathon - Modern Header Component

This repository contains the Header component built for the DogFood Hackathon project.

## 🚀 Features
- **Glassmorphic Design**: Modern backdrop blur and dark mode theme.
- **Responsive Navigation**: Desktop navigation bar + mobile sliding drawer.
- **Interactive Search Bar**: Quick focus shortcut (`Ctrl+K` / `Cmd+K`).
- **Action Elements**: Animated CTA button and cart indicator badge.
- **Pure Vanilla Tech**: HTML5, CSS3, JavaScript (no framework overhead).
